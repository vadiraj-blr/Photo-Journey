Build Phases

How it came together.

The site was built in iterative phases — each one shipping real, usable functionality before moving to the next layer of polish and features.

01
Foundation

Monorepo & Project Scaffold

Established the pnpm workspace monorepo with shared libraries, TypeScript project references, and Replit workflow configuration.

  • pnpm workspace with shared lib/db, lib/api-spec, lib/api-zod
  • Nix environment with Node 24 and PostgreSQL 16
  • Drizzle ORM configured against Neon (cloud PostgreSQL)
  • Replit artifact routing and preview path setup
  • Environment secrets wired (NEON_DATABASE_URL, SESSION_SECRET)
02
Backend

API Server

Built the Express API server that powers all data, authentication, and media operations across the entire site.

  • Admin auth with signed cookie sessions and bcrypt password hashing
  • CRUD routes for trips, photos, articles, comments, reactions
  • Settings API — hero photos, about page content, contact details
  • Google Photos album scraping via /api/photos
  • Analytics / page view tracking
  • Newsletter subscriber management and email notifications
  • Contact form endpoint
  • Dashboard aggregation for admin panel
  • OpenAPI spec + Orval-generated React Query hooks in lib/api-client-react
03
Database

Schema Design & Migrations

Designed and pushed the complete database schema to Neon production using Drizzle Kit.

  • trips — title, location, country, year, story, cover image, travel tips, Google Photos URL, gallery picks, tags
  • photos — linked to trips, image URL, caption
  • articles — field notes with slug, body (Markdown), cover image, publish state
  • trip_comments — visitor comments with moderation flag
  • trip_reactions — per-session like/unlike per trip
  • subscribers — email newsletter signups
  • page_views — analytics event log
04
Web App

Core Web Application

Built the public-facing React/Vite website — the main portfolio experience for visitors.

  • Home page — hero slideshow with eager-loaded high-res images, responsive srcset, trip grid with skeleton loaders
  • Trip page — cover image, story text, travel tips section, masonry gallery, full-screen lightbox with slideshow mode, swipe gestures, thumbnail strip
  • About page — portrait, bio, field notes listing, places word-cloud, contact section
  • Field Note page — Markdown-rendered article with cover image banner
  • Wouter-based routing with scroll-to-top on navigation
  • Framer Motion animations throughout with reduced-motion support
  • Active nav link highlighting
05
Admin

Admin Panel

A comprehensive dark-themed admin dashboard for managing all site content without touching code.

  • Secure login page with signed-cookie session
  • Trip editor — full CRUD, Google Photos URL, gallery photo selection, travel tips, tags, featured toggle
  • Field notes editor — Markdown with live preview, cover image, excerpt, publish/draft toggle
  • Site settings — hero photo selection, about page content, contact details, portrait photo
  • Analytics dashboard — page views, subscriber count, popular trips
  • Comments management panel
06
Mobile

Expo Mobile App

A native-feel iOS/Android app built with Expo and React Native, sharing the same API backend.

  • Always-dark theme with custom colour palette
  • Trip list and detailed trip view with gallery
  • Direct API fetch pattern (not generated hooks) to handle extended trip fields
  • React Native Worklets integrated with pnpm workspace fix for @babel/generator
  • Expo-managed build and QR code preview
07
Media Artifacts

Slides, Video & Countdown

Standalone companion artifacts built alongside the main site for presentations and launch marketing.

  • Portfolio Deck — slide deck using real lh3.googleusercontent.com photo URLs, IG-safe 16:9 layout
  • Launch Countdown — animated countdown page ahead of site go-live
  • Promo Video — motion-graphics video artifact using React + Framer Motion
  • All three registered as separate artifacts with their own Vite dev servers and preview paths
08
Polish & UX Fixes

Refinement Iterations

A sustained round of UI polish, accessibility improvements, and user-reported bug fixes.

  • Hero images: fetchpriority="high", responsive srcSet via gpSrcSet() helper
  • About page portrait — skeleton guard to prevent flash of missing image
  • Featured trip excerpt — sentence-level truncation (no mid-word cuts)
  • Travel tips section — moved above galleries, fixed invisible-element Intersection Observer bug
  • Lightbox — title/location bar, photo counter, swipe gestures, always-visible thumbnail strip
  • Gallery footnote — "Images are high resolution and may take a moment to load"
  • Admin cover image URL field — hint explaining Google Photos direct URL requirement
  • Global focus-visible ring and prefers-reduced-motion CSS
  • ScrollToTop component so every route navigation resets scroll position
