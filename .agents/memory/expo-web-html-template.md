---
name: Expo web +html.tsx static rendering
description: Why +html.tsx is ignored during expo export --platform web and how to fix it.
---

## Rule
`app/+html.tsx` is NOT rendered into the static `dist/index.html` unless `expo.web.output = "static"` is set in `app.json`. Without it, expo-router exports a dumb SPA shell (generated by the built-in `Html` component) and only renders `+html.tsx` in the browser after the JS bundle loads.

**Why:** The Expo CLI export path checks `exp.web?.output` against `['static', 'server']` to decide whether to call `exportFromServerAsync` (which SSR-renders routes via `+html.tsx`) vs. generating a plain HTML shell. Default is SPA mode (no static rendering).

**How to apply:** Whenever `+html.tsx` customizations (font preloads, meta tags, custom styles) must appear in the exported static HTML, ensure `app.json` has:
```json
"web": {
  "output": "static"
}
```

Note: `"output"` is NOT a valid option on the expo-router config plugin (`app.json` → `plugins` → `["expo-router", { ... }]`). It goes only in `expo.web`. Using it in the plugin causes a schema validation error and the export fails.

## CDN font URL pattern
Feather icons are bundled via `@expo/vector-icons`. The correct CDN URL for the font file is:
`https://cdn.jsdelivr.net/npm/@expo/vector-icons@{VERSION}/build/vendor/react-native-vector-icons/Fonts/Feather.ttf`
where `{VERSION}` is the installed version of `@expo/vector-icons` (currently 15.1.1).
